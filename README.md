# Mini 3D FPS

A simple browser-based 3D shooter built with Three.js.

## Run locally

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173>.

## Controls

- **WASD**: Move
- **Mouse**: Aim
- **Left click**: Shoot
- **R**: Reload

## Gameplay

- Click **Start Game** and lock the pointer.
- Shoot incoming enemies before they reach you.
- Survive as long as possible and maximize your score.
